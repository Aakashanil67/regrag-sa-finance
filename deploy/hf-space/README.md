RegRAG answers questions about South African financial regulation from a fixed corpus and cites the page each answer comes from. This Space runs a small local model (Llama 3.2 3B) on free hardware, so it is slower and weaker than the GPT-5.6 Luna setup that was evaluated. The code and results are at https://github.com/Aakashanil67/regrag-sa-finance.
